# Slate

離線的筆記＋資料庫＋待辦工作區，電腦和手機都能用。不用註冊、沒有伺服器：資料只存在你自己的裝置上，
要在兩台裝置之間同步時，輸入一組連結碼，它們就會直接互相傳送。

**馬上用：<https://slate.16888u.com/>**

## 安裝成 App（離線可用）

打開上面的網址，然後：

- **電腦（Chrome／Edge）、Android**：按畫面右下角的「安裝」。
- **iPhone／iPad**：用 Safari 開啟會先看到下載頁，按「下載安裝」，再到「設定」→ 最上方「已下載描述檔」→「安裝」。
  描述檔只會在主畫面加一個 Slate 圖示（它沒有簽署，所以系統會顯示「未簽署」）。不想裝描述檔，也可以用「分享」→「加入主畫面」，結果一樣。

裝好之後不連網也能開、能寫。有新版時，連網開啟一次就會自動更新。
不安裝、直接在瀏覽器分頁裡用也可以，同樣離線可用。

## 跨裝置同步

1. 兩台裝置都打開 Slate，進「設定與備份」→「跨裝置同步」。
2. 其中一台按「顯示連結碼」，另一台按「輸入連結碼」把那 8 個字元打進去。
3. 連上後兩邊的內容會合併。之後只要兩台同時開著 Slate 就會自動同步，不用再輸入連結碼。

要知道的事：

- **沒有雲端**。筆記加密後直接在兩台裝置之間傳送（WebRTC），不經過也不存放在任何伺服器，所以沒有容量上限，
  也沒有帳號可以被盜。代價是**兩台裝置要同時開著才會同步**；分開時各改各的，下次同時開啟時自動合併。
- 配對和找到對方的那一刻需要網路（透過公用的 PeerJS 配對服務牽線，它只看得到亂數代號，看不到連結碼和內容）。
- 兩台在同一個 Wi-Fi 幾乎都連得起來。其中一台用行動網路時，少數電信商的網路會擋直接連線，改連 Wi-Fi 再試。
- 衝突規則：以「一頁、一筆任務」為單位，兩台都改到同一筆時較晚的修改整筆勝出；改到不同筆互不影響。刪除也照同樣規則。
- 版本歷史與外觀等設定不同步；附件會同步。
- 可以連結兩台以上。「停止同步」只會讓這台裝置離開，資料都留著。裝置遺失時，在另一台的裝置清單按「移除」，它就再也連不回來。
- 手機瀏覽器不支援「自動備份到資料夾」，請定期手動匯出，或靠同步讓電腦那份當備份。

## 在手機上用

畫面寬度 900px 以下自動切成手機版面：底部導覽列（首頁／搜尋／新頁面／待辦／頁面）、側邊欄變成抽屜、
選單從底部滑出、待辦清單變成橫向分頁、表格與看板可左右滑動、多欄內容改為上下排列。
拖曳排序在手機上不可靠，請改用「移動到…」或進卡片裡改欄位。

## 自己架一份／開發

需要 Node 20.19 以上。

```
npm install
npm run dev        開發
npm run build      產生 dist/（純靜態檔案，放到任何有 HTTPS 的靜態空間都能用）
npm start          在 http://localhost:5183 預覽建置結果
npm test           單元測試
```

Windows 上可以直接雙擊 `start.bat`。同步功能需要 HTTPS 或 localhost（瀏覽器的加密功能只在安全連線下開放）。

瀏覽器測試：先 `npm run build`、`npm start`，再跑 `node e2e/smoke.mjs`、`round2.mjs`、`round3.mjs`、`mobile.mjs`（手機尺寸＋觸控）；
`node e2e/sync.mjs` 會自己啟動程式和一個本機的配對服務，用兩個瀏覽器驗證連結、同步、離線後合併與停止同步。

推到 `master` 分支會由 `.github/workflows/pages.yml` 自動建置並發布到 GitHub Pages。

## 功能

**首頁與每日筆記**
- 首頁：今天的待辦（可直接勾選、新增）、最近編輯、我的最愛
- 今日筆記：一鍵開啟當天的日誌頁，沒有就自動建立在「日誌」底下

**頁面**
- 每頁可選字型（預設／襯線／等寬）與小字；可列印或存成 PDF
- 無限層級、圖示、封面、我的最愛、全寬、鎖定、副本、移動到…
- 側邊欄拖曳：放到列的上緣／下緣是調整順序，放到中間是變成子頁面；側邊欄可調寬
- 垃圾桶與還原，刪除後有「復原」提示（也可按 Ctrl+Z）
- 版本歷史：編輯時每 10 分鐘自動留存一份，最多 40 份，可預覽與還原
- 空白頁可從範本開始；右側大綱；反向連結

**編輯器**
- `/` 選單：標題、清單、待辦、折疊、引言、程式碼、表格、圖片／檔案、標註、子頁面、內嵌資料庫
- `@` 提及其他頁面（也可直接建立新頁面）
- 多欄排版：`/兩欄`、`/三欄`，或把區塊拖到另一個區塊的左右邊緣；欄寬可拖曳
- 區塊拖曳排序、Markdown 匯入與匯出

**資料庫**
- 屬性：文字、數字、單選、多選、日期、核取方塊、網址、關聯、彙總、公式、建立時間、上次編輯時間
- 檢視：表格、看板、清單、月曆、畫廊、時間軸；每個檢視有自己的篩選、排序、隱藏欄位
- 表格：依單選屬性分組（可收合）、欄寬拖曳、列拖曳排序、底部統計（筆數、加總、平均…）、檢視內搜尋
- 表格鍵盤操作：上下鍵在列之間移動，Enter 確認並往下一列；每列有「開啟／複製／刪除」選單
- 看板可直接新增分組；CSV 匯入（依欄名對應既有屬性，沒有的欄會自動建立並猜測類型）與匯出
- 彙總：沿著關聯讀取另一個資料庫的屬性並加總／平均／計數，結果可再餵給公式
- 每一列都是頁面，點「開啟」從右側滑出預覽，不離開目前畫面
- 可整頁，也可內嵌在任何頁面中

**公式**：屬性寫成 `prop("名稱")`，支援四則運算、比較、`and`／`or`／`not`，以及
`if round floor ceil abs min max concat length contains empty toNumber upper lower now today dateBetween dateAdd`。
例：`if(prop("數量") > 0, prop("金額") / prop("數量"), 0)`

**待辦**
- 今天／最近 7 天／收件匣／自訂清單／月曆／四象限、優先級、重複、子任務、標籤
- 四象限：重要＝優先級中或高，緊急＝明天以前到期；拖曳任務到別的象限會跟著改優先級與日期
- 快速輸入：`明天 交報告 !3 #工作`
- 設了時間的任務到點會提醒（需要應用程式開著）
- 番茄鐘（切換畫面或重新整理都不中斷）、習慣打卡

**資料安全**
- 設定 → 自動備份到資料夾：每 5 分鐘把變動寫進你選的資料夾，每天一檔、保留 14 天
- 手動匯出／還原整包 JSON；可啟用瀏覽器的儲存保護

**AI 助理**（側邊欄 →「AI 助理」）
- 用說的管理工作區：找資料、建立與改寫頁面、整理資料庫、新增與調整任務。助理直接在你的 Slate 裡動手，
  刪除類的動作會先問你；被改寫的頁面可以從版本歷史還原。
- 模型來源自己選，設定只存在這台裝置上（不同步、不進備份）：
  - **API 金鑰**：從選單選服務（Claude、OpenAI、Google Gemini、OpenRouter、DeepSeek、Groq、Mistral、xAI、Together、Cerebras，或任何 OpenAI 相容的接口），
    貼上金鑰後模型清單會自動列出來。金鑰和對話從你的裝置直接送到該服務，沒有中間伺服器；每個服務各記各的金鑰。用量由該服務另外計費。
  - **Claude 訂閱（Claude 桌面版）**：不用金鑰，也不用打指令。電腦上要先有 Claude 桌面版（claude.ai/download；瀏覽器版和 Claude Code 不算）。在助理的模型設定按「下載 Claude 擴充功能」，點兩下下載的 `slate.mcpb`，
    Claude 桌面版會問要不要安裝；接著在 Claude 裡說「連接我的 Slate」，點它給的連結並按確定。之後直接在 Claude 裡說要做什麼，
    由開著的 Slate 分頁執行。兩邊用配對碼互相確認（連結裡就帶著，不用自己輸入），擴充功能不存資料、只接受本站的分頁；
    刪除時 Slate 會跳出視窗問你。只能在電腦上用。
    Claude Code 或其他 MCP 用戶端改用單檔的 `slate-mcp.mjs`（`claude mcp add slate -- node slate-mcp.mjs`，再執行 `node slate-mcp.mjs pair` 取得連結）。
    自己架站的話要設 `SLATE_URL` 和 `SLATE_ORIGINS`。
  - **本機模型**：自動尋找這台電腦上執行中的 Ollama 和 LM Studio，找到就列出已安裝的模型讓你點選，資料完全不離開電腦。
    程式有在跑但不允許網頁連線時，畫面會給出對應的設定步驟（Ollama 是一行可以複製的設定，LM Studio 是介面上的開關）。
    模型要支援工具呼叫；小模型操作工具比較容易出錯。
- 實作：`src/lib/ai/tools.ts` 是和模型無關的工具層（有單元測試），`claude.ts`、`local.ts` 是兩種模型來源，`bridge.ts` 加上 `public/slate-mcp.mjs` 是給 MCP 用戶端的橋；
  `e2e/assistant.mjs`、`e2e/mcp.mjs` 用假模型和假 MCP 用戶端把整個流程跑一遍。改了工具的名稱或參數、或橋接程式本身之後，要執行 `npm run make-mcp` 更新橋接程式裡的工具清單和 `public/slate.mcpb`（有測試會檢查兩者一致）。

**從別的 App 搬過來**（設定與備份 →「從 Notion／滴答清單匯入」，內容是加進來，不會取代現有資料）
- Notion：匯出時選「Markdown & CSV」並包含子頁面，把下載到的 .zip 直接選進來。頁面的階層、資料庫與每一列、
  圖片附件、頁面之間的連結都會保留，全部放在「從 Notion 匯入」這一頁底下。
- 滴答清單／TickTick：設定 → 備份 → 生成備份得到的 .csv。清單、子任務、到期日與時間、優先級、標籤、重複規則、
  完成狀態都會帶過來；同一份備份再匯入一次不會重複。

## 結構

- `src/db.ts` 資料表與所有寫入操作
- `src/lib/logic.ts`、`src/lib/formula.ts` 純邏輯（有單元測試）；`src/db.test.ts` 是資料層測試
- 改資料庫結構或儲存格時一律用 `mutatePage`／`setRowProp`（讀最新值再改），不要用畫面上的舊值直接覆寫
- `src/lib/autobackup.ts` 資料夾備份　`src/lib/templates.ts` 範本　
- `src/lib/link.ts` 連結碼配對、裝置間加密連線　`src/lib/sync.ts` 比對與合併（有單元測試）。
  資料層會自動替每筆寫入蓋上版本 `rev`、刪除留下墓碑（`tombs` 表）
- `src/styles-mobile.css` 手機與觸控版面（最後載入，覆寫桌機樣式）
- `src/components/Editor.tsx` 編輯器與自訂區塊
- `src/components/database/` 資料庫（`DatabaseView` 外殼、`TableView` 表格、`views` 其餘檢視、`PropCell` 儲存格）
- `src/components/Home.tsx` 首頁
- `src/components/tasks/` 待辦、番茄鐘、習慣
